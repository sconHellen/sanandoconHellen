# Maquetas de diseño (solo referencia)

Exportaciones de la herramienta de diseño. **No es código de producción**: `support.js` y `vendor/` son solo el visor.

- `Landing page-html v1/` → contenido, orden de secciones y embudo del landing (su paleta nocturna y sus fuentes NO se usan).
- `SanandoConHellen/` → identidad visual (colores, fuentes, radios, animaciones) y diseño de la app de miembros.

Para verlas: `cd "design/SanandoConHellen" && python3 -m http.server` y abre `Main.dc.html`.

Las fotos de `SanandoConHellen/assets/` se copiaron a `public/images/` con nombres descriptivos:
`hellen-cuencos.jpg` (héroe) y `hellen-retrato.jpg` (Hola, soy Hellen).
